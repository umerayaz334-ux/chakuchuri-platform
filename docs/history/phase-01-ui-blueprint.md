# Phase 1 UI Blueprint

ChakuChuri.pk should feel like a modern B2B service and logistics platform, not a heavy ERP.

## UI Principles

- Customer screens answer: where is my order, what do I owe, and what needs action.
- Admin screens are dense but calm, with fast access to records and details.
- Shipping, manufacturing, payments, messaging and calls remain separate modules linked by customer account.
- Every page needs empty, loading, error and success states.
- Mobile layouts use concise sections, stable controls and no desktop-only workflows.
- Navigation uses durable URLs so refresh and browser history preserve the active page.

## Prototype Coverage

- Public website and authentication
- Customer dashboard, quotations and products
- Manufacturing timeline
- Shipping rate checker and requests
- Payments and customer ledger
- Admin command center and customer profiles
- Messenger with attachments and direct audio calling
- Admin call history
- Users, roles and page access
- Platform appearance, language and connection settings

## Design Language

- Neutral surfaces with dark text and clear status colors.
- Teal primary actions with a restrained gold accent.
- Tight 8px radius, thin borders and restrained shadows.
- Collapsible desktop navigation and purpose-built mobile navigation.
